# PosterPal (free version)

A free poster and caption maker. It is a plain website: no server, no accounts, no payments, no watermark.

Files: index.html, style.css, script.js

## Put it online (all free)
- Netlify Drop: go to app.netlify.com/drop and drag this whole folder onto the page. You get a link in seconds.
- Cloudflare Pages or GitHub Pages: upload these three files and publish.

Keep the three files together in the same folder.
